# ЗаписьPRO

Полноценный рабочий сервис записи клиентов для мастеров, репетиторов, психологов и т.д.

## Возможности

### Для мастеров
- Регистрация и вход
- Личный кабинет со статистикой
- Своя уникальная ссылка для клиентов
- Добавление записей вручную
- Отметка «Выполнено» / «Оплачено»
- Учёт заработка

### Для клиентов
- Запись по ссылке мастера (без регистрации)

### Для тебя (владельца)
- Админ-панель
- Видишь всех мастеров
- Общую статистику и оборот
- Можешь включать/отключать аккаунты

## Запуск

```bash
cd zapis-pro
npm install   # если ещё не ставил
npm start
```

Открой http://localhost:3000

### Админ-вход
На странице входа нажми «Вход для владельца»  
Пароль по умолчанию: **admin123**

(смени его в `server.js` — переменная `ADMIN_PASSWORD`)

## Структура
- `server.js` — бэкенд
- `public/` — фронтенд
- `db.json` — база данных (создаётся автоматически)
